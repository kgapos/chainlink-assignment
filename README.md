# chainlink-assignment

## Local Observability Stack (Docker Compose)

This stack runs a VeChain testnet node and a full observability pipeline
using Prometheus, Loki, Tempo, Grafana, and an OpenTelemetry Collector.
Logs are shipped with Promtail and traces are generated by a sidecar.

### Prerequisites

- Docker + Docker Compose

### Start the stack

```bash
docker compose up -d
```

If the VeChain node reports permission errors on `thor_data`, run:

```bash
docker compose run --rm thor-init
docker compose up -d
```

### Access endpoints

- Grafana: http://localhost:3000 (admin/admin)
- Prometheus: http://localhost:9090
- Loki: http://localhost:3100
- Tempo: http://localhost:3200

### Validate telemetry flow

1. Prometheus targets: http://localhost:9090/targets
   - Expect `vechain-node` and `prometheus` to be up.
2. Grafana dashboard:
   - Open the "Observability Overview" dashboard for node logs and up metrics.
3. Traces:
   - Grafana Explore → Tempo datasource, search recent traces.

### Stop the stack

```bash
docker compose down
```

### Notes

- VeChain node metrics are exposed at `:2112/metrics`.
- Node data is persisted in the `thor_data` Docker volume.
